## Brand & Style

This design system establishes an authoritative, mission-critical posture for national cybersecurity situational awareness and incident orchestration. Engineered for the high-velocity operational context of a Security Operations Center (SOC), the aesthetic merges disciplined institutional governance with futuristic defense-grade computing interfaces.

### Core Visual Philosophy
- **Aesthetic Direction:** Futuristic Glassmorphic Command Grid. Translucent multi-layered surfaces, sub-pixel structural delineation, and targeted luminous accents simulate high-density tactical head-up displays (HUDs).
- **Atmospheric Palette:** Dense abyssal slate-navies form the backdrop to minimize ocular fatigue during 24/7 watchkeeping, illuminated by precise neon cyan and electric blue emissive nodes.
- **Sensory Resonance:** Unshakeable authority, surgical precision, uncompromising vigilance, and decisive technical command.
- **Functional Intent:** High data density without visual friction; immediate state recognition via luminous chromatic signaling (threat levels, cryptographic validations, incident escalation pathways).

## Colors

The palette operates on high-contrast luminescence over light-absorbing base surfaces. Pure white is restricted to primary data readings to avoid optical glare; semantic colors carry distinct operational meanings.

### Functional Roles & Hierarchy
- **Canvas Base (`#0a0f1d`):** Primary canvas void. Absolute background for maximum perceptual contrast of glowing monitors.
- **Surface Elevation (`#0f172a`):** Base slate-navy tier for cards, structural panels, and navigational rails.
- **Primary Cyber Matrix (`#14b8a6` / `#0ea5a3`):** Primary status, safe-state monitoring, operational health telemetry, and standard primary interactions.
- **Secondary Vector (`#0284c7`):** Command links, deep-packet inspection flows, network topology nodes, and auxiliary triggers.
- **Tertiary Synthetic (`#7c3aed`):** Cryptographic signatures, intelligence feeds, automated AI/ML heuristic analysis triggers.
- **Critical Breaches (`#ef4444`):** Active intrusions, critical vulnerabilities (CVSS 9.0+), immediate quarantine alerts.
- **Telemetry Deviations (`#f59e0b`):** Anomalous traffic spikes, certificate expirations, unpatched services.
- **Surface Boundaries:** Fine borders tinted with alpha channels of primary and secondary hues (`rgba(20, 184, 166, 0.15)` and `rgba(2, 132, 199, 0.2)`).

## Typography

The typographic hierarchy implements three distinct operational type engines:

1. **Strategic Titles (Plus Jakarta Sans):** Delivers clean geometry, crisp geometric forms, and high-legibility authority for page titles, mission overviews, and executive dashboards.
2. **Operational Text (Inter):** High x-height, neutral letterforms, optimized micro-display clarity for tabular event streams, incident descriptions, and operational protocols.
3. **Telemetry & Tactical Metadata (JetBrains Mono):** Monospaced, zero-ambiguity characters reserved for IP addresses, cryptographic hashes, CVE designations, time codes (UTC/WIB), and terminal-style telemetry displays. Uppercase transformation applied to micro-tier indicators for instant scannability.

## Layout & Spacing

The structural layout uses an orchestrated 12-column responsive grid with a strict 4px/8px incremental spatial rhythm, engineered for dense multi-monitor console configurations and high-resolution mission wall projections.

### Spatial Architecture
- **Desktop Display (≥1440px):** 12 columns, 24px (`1.5rem`) gutters, 32px (`2rem`) screen margins. Max container constraint: 1800px for panoramic telemetry overviews.
- **Operations Console / Tablet (768px - 1439px):** 8 columns, 16px (`1rem`) gutters, 24px (`1.5rem`) screen margins. Split multi-pane layouts collapse into stacked segmented viewports.
- **Tactical Handheld Mobile (<768px):** 4 columns, 12px (`0.75rem`) gutters, 16px (`1rem`) safe margins. Secondary analytics rails collapse into slide-over security drawers.

### Cyber Grid Matrix Underlay
Layout viewports are grounded with a low-opacity cyber grid background using 32px increments:
```css
background-image: 
  linear-gradient(to right, rgba(14, 165, 163, 0.04) 1px, transparent 1px),
  linear-gradient(to bottom, rgba(14, 165, 163, 0.04) 1px, transparent 1px);
background-size: 32px 32px;
```

## Elevation & Depth

Visual hierarchy uses frosted optical glass physics combined with perimeter luminescence rather than traditional dropped shadows.

### Glassmorphism Stack Architecture
1. **Tier 0 (Sub-Base Grid):** `#0a0f1d` with static vector grid matrix.
2. **Tier 1 (Base Panel Glass):**
   - Background: `rgba(15, 23, 42, 0.65)`
   - Backdrop Filter: `blur(16px) saturate(180%)`
   - Perimeter Border: `1px solid rgba(255, 255, 255, 0.07)`
   - Shadow: `0 4px 24px -1px rgba(0, 0, 0, 0.4)`
3. **Tier 2 (Elevated Command Card / Inspector):**
   - Background: `rgba(15, 23, 42, 0.8)`
   - Backdrop Filter: `blur(24px) saturate(200%)`
   - Perimeter Border: `1px solid rgba(20, 184, 166, 0.25)`
   - Internal Specular Highlight: Top inset `1px solid rgba(255, 255, 255, 0.12)`
   - Shadow: `0 12px 36px -4px rgba(2, 6, 23, 0.6), 0 0 16px -2px rgba(20, 184, 166, 0.1)`
4. **Tier 3 (Overlay / Critical Intercept Modal):**
   - Background: `rgba(10, 15, 29, 0.92)`
   - Backdrop Filter: `blur(32px)`
   - Perimeter Border: `1px solid rgba(2, 132, 199, 0.4)`
   - Outer Emissive Pulse: `0 0 40px rgba(2, 132, 199, 0.15)`

## Shapes

The interface embraces a disciplined, engineered profile with restrained curvature (`roundedness: 1`), reinforcing precision instruments over playful consumer software.

### Curvature Tokens
- **Micro Inputs & Tactical Badges (`0.25rem` / `4px`):** Strict, compact corners for data tags, IP pills, and micro buttons.
- **Component Enclosures & Cards (`0.5rem` / `8px`):** Main structural panels, data cards, modals, and telemetry containers.
- **Tactical Cut-Corners (Special SVG/Clip-Path Masking):** Reserved for national shield emblems, critical threat alert banners, and top-level view switchers (45-degree 6px chamfer) to signify hardened cyber assets.

### Operational Telemetry Cards
- **Construction:** Frosted slate-navy backplate (`Tier 1 Glass`), top edge specular line, sub-pixel edge borders.
- **Header:** Accompanied by monospaced classification tags (e.g., `SEC-LVL: RESTRICTED // UNIT-04`), active status blip, and action controls.

### Domain-Specific Components
- **Live Threat Stream Log:** Monospaced zebra-less list, alternating border-left visual status lines (green/amber/red), sub-second millisecond timestamps, raw JSON packet payload fold-out inspector.
- **Attack Vector Radar Graph / Topology Node Canvas:** Translucent node connectors in `#0284c7`, cluster highlights in `#7c3aed`, compromised nodes flashing `#ef4444`.
- **Gov Agency Defacement Scanner:** Domain inventory list with SSL health ribbons, DNS propagation ticks, and instant automated rollback controls.
